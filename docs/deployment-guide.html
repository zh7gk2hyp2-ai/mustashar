1️⃣ تثبيت البيئة

Node.js 20 LTS

curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

MySQL 8.0

sudo apt-get install -y mysql-server
sudo mysql_secure_installation

Nginx

sudo apt-get install -y nginx

PM2 (لإدارة العملية)

sudo npm install -g pm2

2️⃣ إعداد قاعدة البيانات

سجّل دخول MySQL وأنشئ قاعدة البيانات والمستخدم: 
sudo mysql -u root -p

CREATE DATABASE mustashar_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'mustashar_user'@'localhost' IDENTIFIED BY 'STRONG_PASSWORD_HERE';
GRANT ALL PRIVILEGES ON mustashar_db.* TO 'mustashar_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;
طبّق المخطط والبيانات الأولية: 
mysql -u mustashar_user -p mustashar_db < server/db/schema.sql
mysql -u mustashar_user -p mustashar_db < server/db/seed.sql
⚠️ استبدل STRONG_PASSWORD_HERE بكلمة مرور قوية (20+ حرف عشوائي) وحفظها في .env.

3️⃣ رفع الكود وتثبيت الحزم

انسخ المشروع إلى الخادم: 
git clone https://github.com/zh7gk2hyp2-ai/mustashar.git /var/www/mustashar
cd /var/www/mustashar/server
أنشئ ملف .env من النموذج وعدّل القيم: 
cp .env.example .env
nano .env
ثبّت الاعتماديات: 
npm install --production

4️⃣ ضبط متغيرات البيئة (.env)

القيم الحرجة التي يجب تغييرها:

المتغيرالقيمة المطلوبة
DB_PASSكلمة مرور MySQL (قوية وعشوائية)
JWT_SECRETسلسلة عشوائية 64 حرفاً على الأقل
node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"
ADMIN_PASSWORDكلمة مرور المدير الافتراضي (ستُستخدم مرة واحدة)
ALLOWED_ORIGINShttps://mustashar.tu.edu.sa
SMTP_PASSكلمة مرور حساب البريد noreply@tu.edu.sa
💡 بعد تعيين ADMIN_PASSWORD شغّل: node -e "require('./db/init-admin')" لتحديث الهاش في قاعدة البيانات (اختياري إذا استخدمت seed.sql مباشرةً).

5️⃣ تشغيل التطبيق مع PM2

cd /var/www/mustashar/server
pm2 start server.js --name mustashar --max-memory-restart 512M
pm2 save
pm2 startup systemd

للتحقق من الحالة:

pm2 status
pm2 logs mustashar

6️⃣ ضبط Nginx كـ Reverse Proxy

sudo nano /etc/nginx/sites-available/mustashar
server {
    listen 80;
    server_name mustashar.tu.edu.sa;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name mustashar.tu.edu.sa;

    ssl_certificate     /etc/ssl/certs/tu-edu-sa.crt;
    ssl_certificate_key /etc/ssl/private/tu-edu-sa.key;
    ssl_protocols       TLSv1.2 TLSv1.3;

    client_max_body_size 15M;

    location /api/ {
        proxy_pass         http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header   Upgrade $http_upgrade;
        proxy_set_header   Connection 'upgrade';
        proxy_set_header   Host $host;
        proxy_set_header   X-Real-IP $remote_addr;
        proxy_cache_bypass $http_upgrade;
    }

    location /uploads/ {
        alias /var/www/mustashar/uploads/;
        expires 30d;
    }

    location / {
        root  /var/www/mustashar;
        try_files $uri $uri/ /index.html;
    }
}
sudo ln -s /etc/nginx/sites-available/mustashar /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

7️⃣ تكامل LDAP / Active Directory

في .env فعّل LDAP وعدّل الإعدادات:

LDAP_ENABLED=true
LDAP_URL=ldap://ad.tu.edu.sa:389
LDAP_BASE_DN=DC=tu,DC=edu,DC=sa
LDAP_BIND_DN=CN=svc-mustashar,OU=ServiceAccounts,DC=tu,DC=edu,DC=sa
LDAP_BIND_PASS=SERVICE_ACCOUNT_PASSWORD

يتطلب هذا التكامل:

  • إنشاء حساب خدمة svc-mustashar في Active Directory بصلاحية قراءة فقط.
  • فتح المنفذ 389 (أو 636 لـ LDAPS) من خادم التطبيق إلى خادم AD.
  • تفعيل كود LDAP في server/routes/auth.js (معطّل افتراضياً للتوافق).
📞 تواصل مع إدارة تقنية المعلومات في الجامعة للحصول على بيانات الحساب الخدمي وفتح المنافذ اللازمة.

8️⃣ تكامل Banner (Ellucian)

BANNER_ENABLED=true
BANNER_API_URL=https://banner.tu.edu.sa/api
BANNER_API_KEY=YOUR_API_KEY

يُستخدم للتحقق من رقم المنسوب تلقائياً عند التسجيل. يتطلب:

  • مفتاح API من إدارة Banner في جامعة الطائف.
  • فتح الاتصال من خادم التطبيق إلى banner.tu.edu.sa.

9️⃣ الأمان والصيانة

جدار الحماية

sudo ufw allow 22/tcp   # SSH
sudo ufw allow 80/tcp   # HTTP
sudo ufw allow 443/tcp  # HTTPS
sudo ufw enable

النسخ الاحتياطي اليومي

# أضف إلى crontab -e
0 2 * * * mysqldump -u mustashar_user -pPASSWORD mustashar_db | gzip > /backups/mustashar_$(date +\%F).sql.gz
# احتفظ بآخر 30 نسخة
find /backups -name "mustashar_*.sql.gz" -mtime +30 -delete

تحديث التطبيق

cd /var/www/mustashar
git pull origin main
cd server && npm install --production
pm2 restart mustashar
⚠️ اختبر دائماً في بيئة تجريبية قبل النشر على الإنتاج.
